与 travel-kb 双向打通 · 工作流

1
本工具是日常调度台：录订单、排班、出车单。数据存本机。订单数据（客户、日期、路线、价格）由你录入或从 Excel 导入。
2
在本机跑配套脚本 export_travelkb_data.py，从 travel-kb 导出用车价 / 供应商到 JSON。脚本在工具同目录，输出 travelkb_prices.json。
3
把 JSON 内容粘贴到上方「从 travel-kb 导入参考价」，一键合并进参考价库。这样报价时可直接参考 travel-kb 沉淀的权威价格。
4
周期性地把订单导出为 Markdown，放回 travel-kb 的 wiki 归档。让订单沉淀为知识资产，AI 报价 / 行程时也能引用。

粘贴快速录入订单

粘贴 JSON，支持单条或批量（{ "orders": [...] } / 数组 / 单个对象）。字段：date、time、route（必填）；type（arrival/departure/charter/transfer）、airport、flight、vehicle、pax、guest、contact、driver、plate、quote（对外报价）、cost（成本价）、price（兼容=报价）、status（pending/confirmed/done/cancelled）、note
